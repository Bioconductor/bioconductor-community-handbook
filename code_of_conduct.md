# Code of Conduct {.unnumbered}

The Bioconductor Code of Conduct was initially adapted from the [BioC 2020 Code of Conduct](https://bioc2020.bioconductor.org/code_of_conduct), which itself built on earlier conference-specific documents.

Changes to the Code of Conduct are versioned and tracked over time.
Each translation is version-controlled and corresponds to a specific version of the reference U.S. English document.

::: {.callout-note}
## Code of Conduct translations

Existing translations of the Code of Conduct are currently being transferred into this repository. During this transition, readers are encouraged to consult the [Bioconductor multilingual Code of Conduct site](https://bioconductor.github.io/bioc_coc_multilingual/) for potentially more up-to-date translations.
:::
